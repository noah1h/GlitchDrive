-----------------------------------------------------
Description
-----------------------------------------------------
GlitchDrive is a bold, modern, and fully responsive HTML template built for car dealerships, vehicle listings, and automotive businesses.

It features a glitch-style UI, smooth animations, and dynamic functionality designed to enhance user experience and help users explore, compare, and favorite cars with ease.

Key Features:
- Dark/Light Mode Toggle (with localStorage memory)
- Animated Scramble Text & Button Hover Effects
- Hearted (Favorite) Car System using localStorage
- Responsive Inventory Listings
- Dynamic Car Details Page via JavaScript
- Contact Form with Real-Time Validation
- Clean Code & Modern UI

-----------------------------------------------------
Installation
-----------------------------------------------------
1. Unzip the downloaded folder  
2. Open the `/GlitchDrive` directory  
3. Launch `index.html` in your browser to preview  
4. Read `/documentation/documentation.html` for full setup and customization instructions  
5. Host your site using Netlify, Vercel, Hostinger, or any other static host

-----------------------------------------------------
Customization
-----------------------------------------------------
You can customize layout, colors, and interactivity by editing:

- `index.html` → homepage layout  
- `style.css` → theme colors, typography, responsive styles  
- `script.js` → scramble animation, theme toggle, favorites logic
