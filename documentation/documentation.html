Overview

Thanks for using GlitchDrive — a modern, responsive car dealership template featuring animated text, a glitch-themed UI, and dynamic JavaScript functionality like a scramble hover effect, dark/light mode toggling, a hearted favorites system, and a validated contact form.

Installation

To install and use the template:

  1. Unzip the downloaded folder.
  2. Open index.html in your browser.
  3. Host it using any static host like Netlify, Vercel, Hostinger, etc.

Customization

  • Theme Mode Toggle: The UI supports light/dark modes with persistent localStorage state and a glitch-style transition using `scrambleTo()`.
  • Scramble Animation: Implemented on buttons and scroll-viewed titles via Intersection Observer.
  • Car Liking System: Users can "heart" cars; data is stored in `localStorage` and reflected globally.
  • Contact Form: Real-time validation with inline error messages and a loading spinner on submission (no backend).
  • Details Page: Car data is dynamically pulled from a JS object when a user clicks “View Details.”
  • Responsive Design: Built with Bootstrap 5 and custom styles.

Most changes can be made by editing:

  • index.html – homepage layout
  • style.css – theme colors and styles
  • script.js – interactivity, effects, and logic
