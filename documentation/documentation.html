GlitchDrive Documentation

A comprehensive guide to using and customizing your modern car dealership HTML template with glitch-style aesthetics and advanced features.

🚀 Quick Start: New to GlitchDrive? Start with the Installation section and then explore the Features overview.

GlitchDrive is a cutting-edge car dealership HTML template designed for the modern digital marketplace. Built with a futuristic glitch aesthetic, it combines stunning visual effects with powerful functionality to create an immersive car shopping experience.

This template isn't just another car website – it's a complete digital ecosystem featuring advanced animations, a sophisticated favorites system, responsive design, and seamless user interactions that will set your dealership apart from the competition.

🌟 Key Features

🎨 Glitch Aesthetic Design

Futuristic interface with scramble text animations, neon colors, and cyberpunk-inspired visual effects that create an unforgettable user experience.

❤️ Advanced Favorites System

Users can heart/favorite cars with persistent storage using localStorage. Complete with animated heart icons and dedicated favorites page.

🌙 Dark/Light Mode Toggle

Seamless theme switching with smooth transitions and automatic preference saving. Perfect for user comfort in any lighting condition.

📱 Fully Responsive

Built with Bootstrap 5 and custom responsive breakpoints. Looks stunning on desktop, tablet, and mobile devices.

✨ Rich Animations

Powered by AOS.js and custom CSS animations. Includes scroll-triggered effects, hover interactions, and loading animations.

🎢 Interactive Car Slider

Swiper.js powered carousel with smooth navigation, touch support, and dynamic content loading for showcasing inventory.

✨ Animations & Effects

Scramble Text Animation

The signature scramble effect is applied to buttons and text elements using the scramble-text class:

<button class="scramble-text" data-text="Original Text">
  Original Text
</button>

The animation is handled by JavaScript in script.js:

// Scramble text animation function
function scrambleText(element, finalText, duration = 1000) {
  const chars = '!@#$%^&*()_+-=[]{}|;:,.<>?';
  let iterations = 0;
  const maxIterations = finalText.length;
  
  const interval = setInterval(() => {
    element.textContent = finalText.split('').map((char, index) => {
      if (index < iterations) return char;
      return chars[Math.floor(Math.random() * chars.length)];
    }).join('');
    
    iterations++;
    if (iterations > maxIterations) clearInterval(interval);
  }, duration / maxIterations);
}

AOS (Animate On Scroll)

Scroll-triggered animations are powered by AOS.js. Add animations to any element:

<div data-aos="fade-up" data-aos-duration="600">
  Content appears with fade-up animation
</div>

<div data-aos="fade-left" data-aos-delay="200">
  Content fades in from left with 200ms delay
</div>

Available AOS Animations

  • fade-up, fade-down, fade-left, fade-right
  • slide-up, slide-down, slide-left, slide-right
  • zoom-in, zoom-out
  • flip-up, flip-down, flip-left, flip-right

❤️ Favorites System

The favorites system allows users to save their preferred cars locally using the browser's localStorage. This creates a personalized experience without requiring user accounts.

How It Works

Adding to Favorites

Users click the heart icon on any car card. The JavaScript captures the car data and saves it to localStorage.

 function addToHearted(carName) {
   likedItems[carName] = true;
   saveLikedItems();
   updateHeartedContainerDisplay();
   notifyLikedItemsChange();
   updateTotalPrice();
 }

Removing from Favorites

Clicking a filled heart removes the car from favorites and updates the UI.

function removeFromHearted(carName) {
  delete likedItems[carName];
  saveLikedItems();
  updateHeartedContainerDisplay();
  notifyLikedItemsChange();
  updateTotalPrice();
}

Displaying Favorites

The hearted.html page reads from localStorage and dynamically generates the favorites list.

function updateHeartedItemsDisplay() {
  const swiperWrapper = $('#hearted .swiper-wrapper');
  swiperWrapper.empty();

  const likedCarNames = Object.keys(likedItems);
  if (likedCarNames.length === 0) {
    swiperWrapper.html(`
      <div class="no-likes-message text-center pt-5">

        <div class="title">You haven't liked anything yet.</div>

        <div class="desc">Start exploring and tap the heart to save your favorites!</div>

      </div>
    
    `);
    return;
  }

Heart Counter

The navigation displays the number of favorited items with a dynamic counter that updates in real-time.

function updateHeartedContainerDisplay() {
  const likedCount = Object.keys(likedItems).length;
  const container = $('.hearted-items-container');
  container.attr('data-count', likedCount);

  if (likedCount > 0) {
    container.removeClass('no-likes');
  } else {
    container.addClass('no-likes');
  }
}

📝 Blog System

GlitchDrive includes a fully functional blog system that allows you to share automotive content, tips, and news with your visitors. The blog is built with a dynamic article loading system that keeps content organized and easy to maintain.

🎯 Quick Start for New Users: The template comes with 2 sample articles pre-configured. You can either modify these existing articles or add your own by following the steps below. No database or backend required—everything is managed through simple HTML and JavaScript files.

Blog Structure

The blog system consists of three main components:

📝 What You'll Need:
  • Text Editor: VS Code (recommended), Sublime Text, Notepad++, or any code editor
  • Web Browser: Chrome, Firefox, or Edge for testing
  • Basic HTML Knowledge: Helpful but not required—just follow the examples

📄 blogs.html

Main blog listing page that displays all available articles with preview cards, titles, descriptions, and section summaries.

📖 blogs-article.html

Dynamic article display page that loads content based on URL parameters. All articles are rendered through this single template.

⚙️ blogs.js

JavaScript file that handles article routing, content loading, and dynamic HTML generation for blog posts.

How It Works

Article Navigation

When users click "View article" on the blog listing page, JavaScript captures the article ID and redirects to the article page with a query parameter:

// Redirect buttons with data-article to the article page
      $('.blog-button').click(function(e){
        e.preventDefault();
        const articleId = $(this).data('article');
        window.location.href = 'blogs-article.html?article=' + articleId;
      });

Dynamic Content Loading

The article page reads the URL parameter and loads the corresponding content from the JavaScript object:

$(document).ready(function(){
        const params = new URLSearchParams(window.location.search);
        const article = params.get('article');
      
        if(article === 'suv-vs-sedan'){
          $('#article-title').text('SUV vs Sedan: Which Is Better?');
          $('#article-desc').text('Choosing between an SUV and sedan...');
          $('#article-content').html(`...`);
        }
      });

Common Mistakes to Avoid

Mismatched Article IDs

Problem: The article ID in the blog card's data-article doesn't match the ID in blogs.js

// In blogs.html
      data-article="my-article"
      
      // In blogs.js - MUST MATCH EXACTLY
      else if(article === 'my-article'){

Result: Clicking the button shows a blank page.

Missing Backticks in JavaScript

Problem: Forgetting to use backticks (`) instead of quotes for multi-line HTML

// WRONG - will cause errors
      $('#article-content').html("<div>...</div>");
      
      // CORRECT - use backticks for multi-line content
      $('#article-content').html(`<div>...</div>`);

Result: JavaScript errors and content won't load.

Unclosed HTML Tags

Problem: Forgetting to close <div>, <li>, or other HTML tags in the article content

Result: Page layout breaks or styles don't apply correctly.

Tip: Use a code editor with syntax highlighting like VS Code, Sublime Text, or Notepad++ to catch these errors.

📧 Contact Form Setup

The contact form is a crucial component for lead generation. It requires server-side processing to send emails. Here are several implementation options:

Option 1: PHP Implementation (Recommended)

Server Requirements

  • PHP 7.4 or higher
  • Mail server (SMTP) access
  • PHP mail() function enabled

Configure PHP Handler

Edit php/contact_handler.php with your email settings:

<?php
$to = "your-email@domain.com";
$subject = "New Contact Form Submission";

$first_name = $_POST['first_name'];
$last_name = $_POST['last_name'];
$email = $_POST['email'];
$message = $_POST['message'];

$body = "Name: $first_name $last_name\n";
$body .= "Email: $email\n";
$body .= "Message: $message\n";

$headers = "From: $email\r\n";
$headers .= "Reply-To: $email\r\n";

if (mail($to, $subject, $body, $headers)) {
    echo json_encode(['success' => true]);
} else {
    echo json_encode(['success' => false]);
}
?>

Test the Form

Upload your files to a PHP-enabled server and test the contact form. Check your email inbox and server logs for any errors.

Option 2: EmailJS (No Backend Required)

EmailJS Setup

  1. Create account at EmailJS.com
  2. Connect your email service (Gmail, Outlook, etc.)
  3. Create an email template
  4. Get your Service ID, Template ID, and Public Key

JavaScript Integration

Replace the form submission code in script.js:

// EmailJS integration
emailjs.init("YOUR_PUBLIC_KEY");

document.querySelector('.contact-form').addEventListener('submit', function(e) {
  e.preventDefault();
  
  const formData = {
    first_name: document.querySelector('.first-name-input').value,
    last_name: document.querySelector('.last-name-input').value,
    email: document.querySelector('.email-input').value,
    message: document.querySelector('textarea').value
  };
  
  emailjs.send("YOUR_SERVICE_ID", "YOUR_TEMPLATE_ID", formData)
    .then(function(response) {
      alert('Message sent successfully!');
    }, function(error) {
      alert('Failed to send message.');
    });
});

🔧 Troubleshooting Guide

Common Issues & Solutions

Contact Form Not Working

Problem: Form submits but no email is received

Solutions:
  • Check server error logs for PHP errors
  • Verify SMTP settings in contact_handler.php
  • Test with a simple PHP mail script
  • Check spam/junk folders
  • Ensure hosting provider allows mail() function

Favorites Not Persisting

Problem: Favorited cars disappear after page reload

Solutions:
  • Check browser localStorage in Developer Tools
  • Ensure JavaScript is enabled
  • Test in incognito mode to rule out extensions
  • Verify console for JavaScript errors

Animations Not Working

Problem: AOS animations or scramble text not functioning

Solutions:
  • Check CDN links for AOS.js and jQuery
  • Verify script loading order in HTML
  • Check browser console for JavaScript errors
  • Ensure data-aos attributes are properly formatted

Responsive Issues

Problem: Layout breaks on mobile devices

Solutions:
  • Check viewport meta tag in HTML head
  • Verify Bootstrap CSS is properly loaded
  • Test with browser developer tools device emulation
  • Check for custom CSS overriding Bootstrap styles
